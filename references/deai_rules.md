# 去 AI 味：口播与文案规则（nonameskill 第 3.5 步）

三层，按顺序做：**机器扫（scripts/deai_lint.py）→ 诊断（装了 dbs-ai-check skill 就用它，没装就按 B 节自己通读）→ 改稿（装了 humanizer-zh 就用它）→ 再扫一遍**。
改稿底线：第 1 步事实清单里的数字、日期、名称、"谁能用/官方未公布"这类限定**一个字都不能漂移**；"可能"不能改成"一定"。

## A. deai_lint 的规则（确定性，命中就要处理或说明为什么保留）

| 规则 | 例子 | 改法 |
|---|---|---|
| 新闻腔开头 | 近日/据悉/重磅/正式宣布 | 开头直接讲对观众的事（七条规律第 1、3 条） |
| 套话连接 | 值得一提的是/总而言之/让我们/首先…其次 | 删，直接说 |
| 拔高词 | 里程碑/颠覆/赋能/标志着/重新定义/未来可期 | 换成具体做了什么、对谁有用 |
| 空对比 | 不只是…更是… | 直接说后半句 |
| 意味腔 | 这意味着/这无疑 | 换成具体后果 |
| 书面词 | 迄今/此外/然而/因此/其/该公司 | 到现在/另外/但/所以/它 |
| 分句太长 | 一个分句 >16 字 | 用逗号断开（口播是听的） |
| 数字扎堆 | 一句 >2 个、一段 >4 个 | 只留最炸的一个讲成人话，其余上画面 |
| 英文太多 | 一句 >2 个英文词 | 品牌名说一次，后面用「它」；功能名说中文 |
| 机械排比 | 连续三个分句同一开头 | 合并或换说法；有意的排比全片最多一处 |
| 口头禅超量 | 说白了>1、其实>1、真的>1、直接>2 | 删到上限 |

## B. 规则扫不出、要靠读的（dbs-ai-check + 自己通读）

- **每句都一样的节奏**：主谓宾、主谓宾……读起来像念稿。中间插一句反问或短句（「为什么？」「就这么简单。」）。
- **四平八稳不站队**：全是"有利有弊"。我们要有一句明确判断（七条规律第 6 条），说成观点。
- **假装口语**：硬塞「家人们」「绝绝子」「宝子」这类网络热梗，同样是 AI 味。本账号的语气是"懂行的朋友"。
- **结尾升华**：「让我们拭目以待」「AI 的未来已来」。改成可以照做的结论，加上转发对象。
- **标题、封面和口播三处说法不一样**：要用同一套话，观众才记得住。

## C. 平台文案、公众号正文

同样先跑 `deai_lint.py <文案.md>`，再按 humanizer-zh 改。公众号长文另外检查三点：
- 小标题是不是"01 背景 / 02 影响"这种空壳？要写成观点句
- 每节开头是不是都在铺垫？
- 结尾是不是在总结升华？

## D. 模板指纹（一期 GPT-6 样片经 AI 写作特征检测得出）

用词干净不等于没有 AI 味。那期命中的 6 处里，5 处来自**结构**：
- 开头三件套（钩子+利益+「最后说」）
- 三个例子用同一句式
- 「但这还不是全部」这类零信息转场
- 「所以记住：A 用这个，B 用那个」这种规则式收尾
- 全片每 6~8 秒准时一个转折，情绪曲线太顺

改法：**七条规律是目的，不是句式**。每期换一种写法达到同样的目的：
| 规律 | 别再用的句式 | 换成 |
|---|---|---|
| 悬念 | 「有个坑，最后说」 | 埋一个具体的疑点：「免费用户也能用，只是用的不是同一个GPT-6」 |
| 续命 | 「但这还不是全部」「更关键的是」 | 转场句本身带信息：「速度也变了」 |
| 例子 | 三个「问X→给你Y」 | 一个说细（放开头），其余一句带过，长短错开 |
| 结论 | 「所以记住：…」 | 留一处真实的不确定（「够不够用，我也说不准」），再给建议 |
| 反差 | 拔高一号的大判断 | 落到具体对比：「以前要专门下个App，现在它在聊天里现做一个」 |
| 转发 | 每期同一句 | 换具体对象和理由 |

另外，配音念"最后说""说白了"这类高频词，会把模板感放大，更容易被听出来。
